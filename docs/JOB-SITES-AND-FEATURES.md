## رابعًا: خارطة الناقص (بترتيب الأولوية)
1. توليد PDF للسيرة + Cover (يعمل serverless).
2. إضافة متصفح لملء ATS (Greenhouse/Ashby/Lever) — البوكماركلت موجود كبداية.
3. بحث محفوظ + تنبيه عند وظائف جديدة مطابقة (بلا تقديم تلقائي).
4. طبقة AI provider ثم: تحضير مقابلات + RAG + أسلوب Mirror.
5. محلي فقط (لا يدخل العامة): Gmail/Telegram + مفاتيح Adzuna + السيرة الشخصية.
