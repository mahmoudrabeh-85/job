# PROJECT.md — Job Intelligence Platform

## الرؤية
منصة ذكية لإدارة دورة البحث عن الوظائف بالكامل (اكتشاف → فهم → مطابقة →
ترتيب → تجهيز → تقديم → متابعة → مقابلة → تعلم → تحسين)، تتطور تدريجيًا
من المشروع الحالي **بدون إعادة بناء** (Preserve, Don't Rebuild).

المصدر الكامل: ملف PRD في جذر المشروع (`*_PRD.md`).

## القواعد الملزمة لكل Coding Agent
1. اقرأ ملفات الحالة أولًا: `.agent/TASKS.md` ثم `.agent/DECISIONS.md` ثم
   `.agent/CONTEXT.md` — ولا تعيد قراءة كامل التاريخ.
2. افحص الكود الحالي قبل أي تعديل، وأعد استخدام ما هو صالح.
3. ممنوع حذف features مستقرة أو إعادة كتابة أجزاء عاملة دون سبب موثق.
4. تغييرات صغيرة قابلة للاختبار فقط، مرحلة واحدة في كل مرة.
5. بعد كل مرحلة: حدّث `TASKS.md` + `CHANGELOG.md` + سجّل القرارات المهمة.
6. ممنوع إرسال رسائل أو تقديم طلبات توظيف تلقائيًا دون موافقة المستخدم.
7. الريبو **عام** — ممنوع أي بيانات شخصية/أسرار في ملفات متعقبة.

## ملفات الذاكرة الموجودة (لا تكررها)
- `AGENTS.md` + `INDEX.md` + `PROGRESS.md` + `NEXT_STEPS.md` + `DECISIONS.md`
  في الجذر (محلية فقط — محجوبة عن git، فيها تاريخ النشر والأمن).
- `.agent/` هنا للهندسة والمهام (قابلة للنشر، بلا أسرار).

## Definition of Done (مختصر)
الكود يعمل + لا regressions + error handling + توثيق محدث +
`TASKS.md` و`CHANGELOG.md` محدثان.
